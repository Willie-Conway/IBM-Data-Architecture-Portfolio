**Migration Script Example**:
```python
# RDBMS to NoSQL Migration
import mysql.connector
from pymongo import MongoClient

# Extract from MySQL
mysql_conn = mysql.connector.connect(
    host="localhost",
    user="root",
    password="password",
    database="product_catalog"
)

cursor = mysql_conn.cursor(dictionary=True)
cursor.execute("SELECT * FROM products")
products = cursor.fetchall()

# Load into MongoDB
mongo_client = MongoClient('localhost', 27017)
db = mongo_client['product_catalog']
collection = db['products']
collection.insert_many(products)

print(f"Migrated {len(products)} products to MongoDB")
```

-- Column-level encryption in MySQL
ALTER TABLE customers 
MODIFY COLUMN addressLine1 VARBINARY(255);

UPDATE customers 
SET addressLine1 = AES_ENCRYPT(addressLine1, 'encryption_key')
WHERE customerNumber > 0;

-- Role-based access control
CREATE ROLE 'sales_rep';
GRANT SELECT, UPDATE (creditLimit)

### 📈 **Chicago Public Data Analysis**

**Scenario**: Comprehensive analysis of crime, school, and socioeconomic data for urban planning.

**Key Queries**:
```sql
-- Crime trends near schools
SELECT 
    cs.community_area_name,
    COUNT(c.case_number) as crime_count,
    AVG(cs.safety_score) as avg_safety_score,
    cs.hardship_index
FROM chicago_crime c
JOIN chicago_schools cs 
    ON c.community_area = cs.community_area
WHERE c.location_description LIKE '%SCHOOL%'
GROUP BY cs.community_area_name
ORDER BY crime_count DESC;

-- Correlation analysis
SELECT 
    hardship_index,
    AVG(safety_score) as avg_safety,
    AVG(college_enrollment) as avg_college_enrollment
FROM chicago_socioeconomic
GROUP BY hardship_index
ORDER BY hardship_index;
```
